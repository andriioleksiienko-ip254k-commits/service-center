# План для застосунку: Вебзастосунок сервісного центру комп'ютерної техніки

## 1. Опис предметної області
**Тема:** Вебзастосунок сервісного центру з онлайн-замовлення та супроводу послуг ремонту комп’ютерної техніки.
**Проблема:** У невеликих сервісних центрах обробка звернень клієнтів, збір інформації про конфігурацію пристроїв та трекінг статусів ремонту часто виконуються вручну. Це призводить до децентралізації даних, ускладнює контроль життєвого циклу заявок, спричиняє затримки в інформуванні клієнтів та знижує ефективність персоналу.

## 2. Основні сутності
* **Послуга (Service):** Запис про тип робіт (ідентифікатор, назва, детальний опис, категорія, доступність).
* **Заявка (Request):** Сутність, що пов'язує клієнта з послугою (специфікації обладнання, опис несправності, поточний статус, вартість, звіт про роботи).
* **Користувач (User):** Профіль із розмежуванням ролей (Клієнт, Працівник).

## 3. Групи користувачів та їхні потреби
* **Клієнт:** Потребує доступу до каталогу послуг, створення заявок із деталізацією параметрів пристрою та проблеми, а також відстеження статусу звернень.
* **Працівник:** Потребує спеціалізованої панелі для перегляду, фільтрації та обробки заявок, зміни їхніх статусів, внесення вартості робіт і керування номенклатурою послуг.

## 4. Головні сценарії
1. Перегляд і пошук послуг сервісного центру.
2. Створення заявки на ремонт із зазначенням специфікацій пристрою та опису несправності.
3. Моніторинг клієнтом історії та поточного статусу активних заявок.
4. Обробка заявок працівником (зміна статусу, внесення вартості та результатів робіт).
5. Керування переліком доступних послуг працівником.

## 5. Основні функції та сторінки
**Основні функції:** перегляд і пошук послуг, створення та редагування заявок, перегляд історії звернень, зміна статусу ремонту, додавання вартості робіт, керування каталогом послуг.
**Основні сторінки:** Головна, Каталог послуг, Деталі послуги, Створення заявки, Редагування заявки, Особистий кабінет клієнта, Панель працівника.

## 6. Стан реалізації (Л 1.1)
**Реалізовано зараз:**
* Базова структура ReactJS-проєкту (Vite).
* План проєкту та архітектурний задум.
* Локальні дані каталогу послуг.
* Компонентна основа сценарію перегляду каталогу послуг (статичний UI без повноцінної маршрутизації).

**Заплановані майбутні функції:**
* Декомпозиція та створення повторно використовуваних UI-компонентів.
* Керування станом (useState, Context API) для фільтрації та чернеток заявок.
* Маршрутизація (React Router) для переходів між сторінками.
* Форми створення/редагування заявок із клієнтською валідацією.
* Асинхронна інтеграція даних (сервісний рівень).
